# PanelMin Tools v2.0

## 🔍 Advanced Admin Login Finder & Database Scanner

### 🚀 Features
- ✅ **Admin Path Finder** - Scan 40+ admin login paths
- ✅ **Login Panel Scanner** - Find working admin panels
- ✅ **Database Scanner** - Detect phpMyAdmin, Adminer, etc
- ✅ **XLS Export** - Export all results to Excel format
- ✅ **Storage Manager** - Manage scan results
- ✅ **Color-coded Output** - Green = Working, Red = Failed
- ✅ **Thread Support** - Fast scanning

### 📋 Installation
```bash
# Clone repository
git clone https://github.com/username/panelmin-tools.git
cd panelmin-tools

# Install dependencies
pip install -r requirements.txt

# Run
python main.py
